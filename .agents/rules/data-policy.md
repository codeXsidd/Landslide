# NER-SAGE Data Policy

## Provenance — Required Fields

Every data item entering the evidence store MUST include:

```json
{
  "source": "string — data origin (sentinel_1 | imd_rainfall | citizen_report | osm | manual)",
  "source_type": "string — category (satellite | rainfall | terrain | human | official | derived)",
  "timestamp": "ISO8601 datetime with timezone",
  "location": { "type": "Point", "coordinates": [lon, lat] },
  "evidence_type": "string",
  "freshness": "HIGH | MEDIUM | LOW | UNKNOWN",
  "reliability": "float 0-1",
  "is_simulated": "boolean — MUST be true for all demo/synthetic data",
  "model_version": "string | null — for derived/predicted values"
}
```

Items missing any of these fields must be rejected with a 422 error.

## Simulation Labelling

- All data generated by `scripts/generate_synthetic_data.py` sets `is_simulated: true`.
- The API must propagate this flag in every response that includes simulated data.
- The frontend must display a visual indicator (⚠️ SIMULATED DATA) when `is_simulated: true`.
- SIH demo mode must not obscure the simulation flag.

## Freshness Thresholds

| Source | HIGH | MEDIUM | LOW |
|--------|------|--------|-----|
| Satellite (Sentinel) | < 2 days | 2–7 days | > 7 days |
| Rainfall observation | < 3 hours | 3–24 hours | > 24 hours |
| Rainfall forecast | < 6 hours | 6–24 hours | > 24 hours |
| Ground / citizen report | < 6 hours | 6–24 hours | > 24 hours |
| Road status | < 1 hour | 1–6 hours | > 6 hours |

## Missing Data Handling

- Missing evidence type → classify as `UNKNOWN` (not `LOW` or `SAFE`).
- Missing satellite → flag as `STALE` after threshold, not as absence of risk.
- Missing ground report → trigger next-best-evidence query, not assumption of safety.
- No feature imputation may silently produce lower risk estimates for missing data.

## Data Retention (Production guidance)

- `audit_logs` → 7 years (regulatory requirement)
- `human_decisions` → 5 years
- `risk_predictions` → 2 years
- `weather_observations` → 1 year
- `citizen_reports` + images → 90 days (or as per government policy)
- Redis keys → always set TTL, no TTL-less keys allowed

## External Data Sources

Approved sources for real (non-simulated) data:

| Source | Data Type | License |
|--------|-----------|---------|
| SRTM / Copernicus DEM | Terrain elevation | Open |
| OpenStreetMap | Roads, buildings, villages | ODbL |
| IMD Open Data | Rainfall observations | Government open |
| Sentinel-1/2 via Copernicus | SAR / optical satellite | Open |
| NDMA Landslide Inventory | Historical events | Government |
| BSDMA / State DMA | State-level inventory | Government |

Do NOT use proprietary data sources without explicit licensing clearance.

## Real-Time Data (MVP Scope)

In MVP / SIH demo, all environmental data is synthetic.
Real-time API integrations (IMD feed, Sentinel Hub) are planned for post-SIH.
Any real-time integration must be clearly documented with source API, license, and refresh schedule.
